# Relay benchmark — 2026-08-29 (production-readiness branch, 4beb43e)

Host: Apple Silicon, 10 schedulers, OTP 29 / Elixir 1.20.3, macOS. Run while
five review agents were executing test suites concurrently (load average
> 40), so absolute numbers are pessimistic; the structural results
(bounded queues, zero contention retries, slow-client isolation) are what
this record pins.

Command:

```sh
mix bench -- --packets 2000 --sizes 8,64,1280,65536 --slow-packets 2000 --slow-delay-ms 20
```

- Idle connection: **23 819 B** (13 336 B of outbox tables; was ~63 KB before B6).
- Slow-client isolation: 2 001 packets at a 20 ms-delayed reader → 1 968
  head replacements, 0 tail drops, 32 retained, writer mailbox 0;
  independent flow latency **22 µs**, 0 contention retries. `bounded: true`.
- BEAM memory delta over the whole run: 689 KB.

Open question recorded for follow-up: a ~6 ms latency mode appears at p95
for small packets and p50 for large ones with zero ring contention. It is
consistent with a timer or TCP delayed-ACK interaction in the benchmark
harness rather than queueing; re-measure on an idle Linux host and
inspect the writer's retry timer / `nodelay` before treating it as a
relay property. Capacity targets remain deferred per PLAN §11 until a
production host is available.
